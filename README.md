# sales_analysis_report
### Sales Analysis Report – Description

 This Sales Analysis Report is an interactive **Power BI dashboard** designed to provide a clear overview of sales performance across different **sub-categories, regions, countries, and order dates**.

 The dashboard includes:

 - **Key Performance Indicators (KPIs):**
  - **Total Sales:** 2.30M
  - **Total Profit:** 286.40K
  - **Total Quantity:** 38K
  - **Total Discount:** 1.56K
- **Sales by Sub-Category:** A funnel-style visualization compares sales across products such as Phones, Chairs, Storage, Tables, Binders, Machines, Accessories, and others.
- **Sales by Region:** A pie chart shows the distribution of sales across regions, including **West, East, Central, and South**.
- **Sales by Country/Region:** The dashboard shows that the **United States accounts for almost all recorded sales**, with a very small contribution from Asia in the displayed data.
- **Sales by Order Date:** A time-series chart illustrates how sales fluctuate over the order-date range and highlights periods with significant sales spikes.
- **Profit by Country/Region and Category:** A table provides a more detailed breakdown of profit by country and product category.
